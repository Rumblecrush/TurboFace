# TurboFace 0.18.1

TurboFace 0.18.1 corrects the public packaging of the first unified
multi-client release.

## Changes

- Excludes the source-only `Save-TurboFaceForever.bat` launcher from public
  addon ZIPs so CurseForge can validate the Forever package.
- Retains the underlying Windows PowerShell and Linux/Proton SavedVariables
  snapshot tools in the Forever package.
- Adds automated coverage preventing batch launchers from entering future
  release archives.
- Contains no gameplay or SavedVariables schema changes.

## Packages

- `TurboFace-Classic-0.18.1.zip` — World of Warcraft Classic Era 1.15.9
- `TurboFace-Forever-0.18.1.zip` — World of Warcraft Forever 1.60.1

Install only the package matching your client. Each archive extracts to a
top-level `TurboFace/` addon directory.
