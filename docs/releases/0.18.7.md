# TurboFace 0.18.7

TurboFace 0.18.7 restores and modernizes several Forever features for the
Midnight-era API, adds new interface controls and movers, and refreshes the
built-in Rumblecrush preset. Classic Era is rebuilt from the same verified
unified source while retaining its client-specific behavior.

## Highlights

- Restored the Forever Class Features family through supported, secret-safe
  APIs, including Battle Shout and other class buff reminders plus reduced
  Warrior Overpower and Revenge indicators.
- Updated Forever's Skill Tracker for `C_SkillInfo` and removed duplicate
  profession entries.
- Hardened target castbars against secret cast GUIDs and unreadable timing,
  preventing taint comparisons and cadence division-by-zero failures.
- Corrected nameplate buff geometry and aligned target-debuff borders with the
  nameplate aura style.
- Added a Forever-only Minimap edge-placement option for Blizzard Edit Mode,
  and corrected TurboFace minimap-button dragging to use direct cursor-angle
  placement.
- Added the Forever Recipe / Alert Toasts mover for Blizzard's “New Recipe
  Learned” stack.
- Added a live Grocery Button Icon Size control.
- Greyed out junk-marked bag icons to make their pending-sale state clearer.
- Marked Leash Timer unavailable on Forever until the client exposes reliable
  per-enemy attribution; Classic behavior is unchanged.
- Refreshed Rumblecrush's built-in preset from the supplied 2026-09-29
  schema-79 export, including its current mover, aura, minimap, Grocery, and
  module settings.
- Expanded regression coverage and documented the complete development-to-
  CurseForge release workflow.

Portable SavedVariables remain at schema version 79.
