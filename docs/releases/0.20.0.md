# TurboFace 0.20.0

TurboFace 0.20.0 adds a saved sticky note and weapon-stone reminders, fixes
class spell-rank detection after trainer visits, and prevents a dungeon
swing-timer error involving protected target identities.

## New features

- **Sticky Note:** Enable it in Options > Speedrun, then open it with
  `/tf note` or `/tfnote`. Drag the header to move it, collapse it to the
  header, or close it. Text, position, and collapsed/open state persist per
  character. The dark background is easier on the eyes, and the feature
  remains dormant when disabled.
- **Weapon stones:** The Class reminder queue now checks both hands for an
  uncoated melee weapon and a compatible, level-eligible sharpening stone or
  weightstone in your bags. Supports ordinary Rough through Dense stones.
  Existing temporary enchants, poisons, and imbues satisfy the reminder.
  Enabled by default, with a toggle in Class Features; hidden during combat
  and while dead. Keep the queue's “Only show while in combat” option off to
  see this out-of-combat reminder.

## Fixes

- Class Training uses explicit learned spell IDs and client-specific rank
  replacement chains across all nine classes, preventing starter-rank aliases
  from incorrectly hiding later ranks.
- Trainer visits preserve rank metadata when the client omits rank labels,
  and resolve ambiguous spell families using catalog rank and level data.
- The training queue respects the same learned-rank result as the list.
- Target and nameplate swing timers reject unreadable GUIDs before cache
  lookup, avoiding the secret-table-key error reported in dungeons.

Portable SavedVariables remain at schema version 79. Existing settings and
character data are preserved.
