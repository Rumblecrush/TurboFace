# TurboFace 0.18.8

TurboFace 0.18.8 is a compatibility patch for the latest WoW Forever beta
update, alongside the completed Lvl1 Quick Setup Blizzard-settings support.

## Highlights

- Fixed Forever nameplate `FrameMeasurement` errors introduced by beta build
  70170. The Forever package now selects its safety policy from package identity
  rather than fragile runtime version/interface/project values, preventing
  Classic-only native anchor restoration from running on restricted Forever
  nameplates.
- Restored all Forever-specific adapters and protected-frame boundaries that
  were incorrectly disabled by the client-identity drift.
- Lvl1 Quick Setup now captures Mouseover Cast preferences and the six Map &
  Quest Log Map Filter choices.
- For the Forever Map Filter CVars that require an explicit TurboFace-owned
  click, Quick Setup presents a verified one-time Apply prompt after automatic
  restoration; successful application is recorded for the stored profile.
- Added `/tf mapfilterprobe` and `/tf mapfilterprobe objectives` for bounded
  compatibility diagnostics of the Map Filter native setters.

Portable SavedVariables remain at schema version 79.
