# TurboFace 0.19.1

TurboFace 0.19.1 is a focused hotfix for movable nameplate combo points and
starter-spell ranks in Class Training.

## Highlights

- Forever nameplate debuffs now follow an addon-owned movable anchor guide.
  Moving combo points downward dynamically releases their reserved space, while
  the default upper position continues to keep debuffs clear of the combo row.
- The aura fix does not reanchor Blizzard's secret-bound AuraContainer after it
  has been attached, preserving the Midnight-safe ownership boundary.
- Class Training now matches the exact spell ID in each live spellbook slot to
  the class rank catalog.
- Starter abilities whose first trainer purchase is Rank 2—including Sinister
  Strike and Heroic Strike—no longer lose Rank 2 while still showing Rank 3.
- Learned higher ranks continue to collapse their older rows correctly, and the
  fallback applies across all class starter-spell families rather than using
  Rogue- or Warrior-specific exceptions.

Portable SavedVariables remain at schema version 79.
