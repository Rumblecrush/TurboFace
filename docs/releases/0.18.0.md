# TurboFace 0.18.0

TurboFace 0.18.0 is the first unified multi-client release. Classic Era and
WoW Forever are now developed from one layered source repository and published
as separate installable packages.

## Highlights

- Introduces an official WoW Forever package alongside the Classic Era package.
- Shares portable feature logic across both clients while retaining explicit
  compatibility, provider, and native UI ownership boundaries.
- Preserves Classic Era behavior and portable SavedVariables schema version 79.
- Keeps Forever-specific protected-frame and secret-value handling isolated in
  its compatibility and adapter layers.
- Adds automated architecture verification, Lua compilation, runtime-contract
  regression tests, package validation, GitHub Releases, and separate
  CurseForge uploads.

## Packages

- `TurboFace-Classic-0.18.0.zip` — World of Warcraft Classic Era 1.15.9
- `TurboFace-Forever-0.18.0.zip` — World of Warcraft Forever 1.60.1

Install only the package matching your client. Each archive extracts to a
top-level `TurboFace/` addon directory.
