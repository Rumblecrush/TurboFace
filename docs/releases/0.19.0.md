# TurboFace 0.19.0

TurboFace 0.19.0 makes quest automation safer, restores accurate ranked class
training on WoW Forever, and introduces a Blizzard-inspired nameplate combo-point
presentation shared by both supported clients.

## Highlights

- Auto Quest Accept and Auto Quest Turn-in remain independent, but now automate
  only ordinary one-time quests. Repeatable, daily, and weekly quests remain
  manual so item-consuming hand-ins cannot drain an entire stack.
- Quest automation yields to vendor access when an NPC provides both services,
  leaves gold/currency-cost completions manual, avoids re-accepting Blizzard
  auto-accepted quests, and treats inaccessible Forever quest identity as unsafe.
- Class Training now uses the live spellbook rank as the authority for ranked
  abilities. Higher Warrior ranks such as Battle Shout, Rend, and Heroic Strike
  no longer disappear because Forever reports the learned spell family as known.
- Trainer rows retain their explicit `(Rank N)` suffix even when localized spell
  subtext has not loaded, with refined rank-label placement.
- Rogue and Druid target-nameplate combo points now use layered 11px gold rims,
  9px black wells, 7px red fills, and upper-right highlights for a rounded native
  appearance.
- Added a live, profile-saved Combo Point Y Offset slider from `-50` to `3`.
  The existing above-name placement remains the default and maximum, while the
  row can be moved beneath the nameplate.

Portable SavedVariables remain at schema version 79.

- `TurboFace-Forever-0.19.0.zip` — World of Warcraft Forever 1.60.1
