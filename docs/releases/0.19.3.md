# TurboFace 0.19.3

TurboFace 0.19.3 adds a safe mover for Forever's native target-unit castbar
and refreshes the built-in Rumblecrush preset from the latest live profile.

## Highlights

- Forever players can position Blizzard's native **Target Unit Cast Bar** from
  TurboFace's Blizzard Movers section. TurboFace moves only the native bar's
  anchor and leaves cast state, rendering, animations, and interaction under
  Blizzard ownership.
- The mover reapplies its position after Blizzard target and aura layout passes,
  defers protected writes during combat, and restores Blizzard's layout when the
  mover or the global Movers module is disabled.
- Position-only movers do not expose Hide or Click Through controls, preventing
  those generic controls from changing native-frame behavior.
- `/tfmove targetcastprobe` reports the resolved native frame, protection state,
  anchor ownership, deferred state, geometry, and last write error.
- **Rumblecrush's Preset** is refreshed from the 2026-10-06 profile export. It
  positions the native target castbar at `CENTER (145, -375)`, moves Target of
  Target to `CENTER (350, -260)`, and enables nameplate swing timers and
  Speedrun Splits.
- The Forever-only native castbar mover data is safely inert in the Classic
  package; the shared preset updates continue to apply normally.

Portable SavedVariables remain at schema version 79.
