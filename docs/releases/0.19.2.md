# TurboFace 0.19.2

TurboFace 0.19.2 makes nameplate combo points persist on their actual target
while preserving Classic's single-target ownership rules.

## Highlights

- Combo points remain visible on their target's nameplate after deselecting it
  or selecting another unit, much like retained nameplate debuffs.
- Only the current target is queried. TurboFace stores the last readable count
  in addon-owned per-nameplate state and never probes protected non-target data.
- Earning the first combo point on a different target transfers ownership and
  immediately clears every older visible combo snapshot.
- Nameplates with zero combo points show no combo row, whether selected or not.
  Positive snapshots continue to display the full five-slot progression row.
- Nameplate removal and pooled-frame reuse clear retained snapshots so combo
  points cannot leak onto another unit.
- Forever's detached aura guides release or restore combo-row spacing whenever
  a retained row changes visibility, without reanchoring secret-bound aura
  containers.
- Druid form transitions hide retained rows outside Cat Form and restore valid
  positive snapshots on returning to Cat Form.

Portable SavedVariables remain at schema version 79.
