# TurboFace 0.19.4

TurboFace 0.19.4 fixes starter-rank detection in Class Training, including
Forever spellbook aliases that could hide untrained Warrior abilities.

## Highlights

- Learned-rank detection prefers the base spellbook slot identity over an
  active spell override. Heroic Strike and Rend Rank 2 remain available for
  training when the character still knows only their starter ranks.
- Catalog level requirements cap impossible future-rank aliases, keeping
  Battle Shout Rank 2 in a level-10 Warrior's future training list. The cached
  snapshot refreshes when the character's level changes.
- Heroic Strike Rank 2 now correctly requires Rank 1 instead of itself.
- Both Classic and Forever include the shared training fixes and modern
  spellbook compatibility fallback.

Portable SavedVariables remain at schema version 79.
