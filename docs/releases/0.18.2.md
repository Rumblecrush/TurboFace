# TurboFace 0.18.2

TurboFace 0.18.2 introduces a Forever nameplate power overlay, improves
detached nameplate layering, and retires the temporary
SavedVariables recovery system now that the client handles normal addon saves
reliably.

## Highlights

- Added a detached, secret-safe **Overlap Power Bar** implementation for WoW
  Forever nameplates. Power normalization stays inside the supported client API
  and the overlay does not mutate Blizzard's protected nameplate objects.
- Fixed TurboFace nameplate health text and power overlays appearing above open
  menus or interface panels.
- Kept health text visually above the overlapping power fill and restored the
  intended size and vertical alignment.
- Marked known-incomplete Forever features as visible but disabled, with the
  tooltip “This feature is currently disabled on Forever.”
- Added the Forever-only `/tf dev bypass [on|off|status]` command for controlled
  testing of those restricted features. The override is stored outside portable
  profiles and deeper client safety checks remain active.
- Promoted the validated Forever configuration to client-owned defaults without
  overwriting existing user settings.
- Removed the retired Forever SavedVariables restore payload and snapshot tools.
- Expanded regression and architecture verification for the new policy,
  packaging, and runtime boundaries.

Classic Era is rebuilt and published from the same verified unified source.
This release does not change Classic gameplay or portable SavedVariables schema
version 79.
